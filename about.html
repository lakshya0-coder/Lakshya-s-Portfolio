about

A student who'd rather ship a rough version than talk about a perfect one.

Third-year BCA student in Sikar, Rajasthan — building working software while I learn, not after.

I'm a third-year BCA student at Sobhasaria Group of Institutions in Sikar, Rajasthan, holding an 8.5+ SGPA while building real, working software on the side. I'm currently strengthening my footing in Data Science, AI, and Machine Learning.

What I care about is the full path from a rough idea to something a stranger can actually run: a trained model, an API that serves it, an interface that makes it usable, and documentation that means I don't have to be in the room for it to make sense.

I use AI coding tools — Claude, the Gemini API — as part of how I build, the way I'd use a compiler or a linter. They speed up the work; they don't replace understanding what the code does.

Outside of coursework, I've interned on ML model lifecycle and generative AI work, and I keep a running set of side projects — from prediction APIs to full front-end builds — to stay hands-on between semesters.
